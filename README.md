# River Raid — Amiga-style remake (browser)

Классический шутер с видом сверху: самолёт летит вверх по реке,
стреляет по кораблям, катерам, вертолётам, вражеским самолётам
и танкам на мостах. Оптимизировано под мобильный браузер.

## Управление
- **Ведите пальцем** по экрану — самолёт следует за пальцем
- **Удержание** — непрерывный огонь
- **Кнопка 💣** — бомба (уничтожает всё на экране, 2 шт. за игру)
- Кнопка **паузы** сверху справа

На клавиатуре: WASD / стрелки — полёт, Space — огонь, B — бомба, P — пауза, M — звук.

## Особенности
- Процедурная генерация реки (песок, вода, волны) — бесконечная
- Канистры топлива на берегу — заправь, иначе упадёшь
- Мосты с танками блокируют пули — перелети или обстреляй до моста
- Враги: катер (30), корабль (50), самолёт (100), вертолёт (150), танк (100)
- Скорость и плотность растут с каждым этапом
- Рекорд сохраняется в localStorage
- Звук — WebAudio (синтез), без внешних файлов
- Чистый Canvas 2D, ноль зависимостей

## GitHub Pages
Игра разворачивается автоматически через GitHub Actions при пуше в `main`.
После деплоя открой: `https://<user>.github.io/river-raid/`

## Локальный запуск
```
python3 -m http.server 8000

```
